# 📊 Survey Feedback Analyzer – Python Fundamentals

## 📌 Project Overview
The **Survey Feedback Analyzer** is a Python-based project designed to collect, clean, and analyze customer survey feedback.

This project applies fundamental Python programming concepts to extract meaningful insights from textual feedback and understand customer satisfaction through ratings.

## 🎯 Objectives
- Collect and store survey feedback.
- Perform basic text cleaning and preprocessing.
- Analyze frequently used words in feedback.
- Calculate average customer ratings.
- Identify the longest feedback comment.
- Extract unique words from all feedback entries.
- Sort feedback based on ratings.

## 📋 Project Workflow

### 1. Preloaded Feedback Data
Created a dictionary of lists containing 10 predefined customer feedback entries with serial numbers, names, feedback comments, and ratings.

### 2. Add More Feedback
Collected additional feedback from users, including name, written feedback, and rating (1–5). Automatically generated serial numbers and appended new entries.

### 3. Text Cleaning
Cleaned feedback entries by:
- Removing punctuation.
- Removing extra spaces.
- Removing leading and trailing spaces.
- Converting text into lowercase.

### 4. Word Count Insights
Created a user-defined function `count_word_in_feedbacks()` to count the number of feedback entries containing specific words:
- Good
- Poor
- Excellent

### 5. Final Summary & Insights
Generated meaningful insights by:
- Displaying the final cleaned feedback data.
- Calculating the average rating.
- Identifying the longest feedback comment based on word count.
- Extracting unique words using Python sets.

### 6. Sorting Feedback by Rating
Used `zip()` and `sorted()` to arrange feedback entries from highest to lowest rating.
